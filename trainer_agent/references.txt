Project Structure
=================

trainer_agent/
├── __init__.py
├── apps.py                 # Django app config
├── schemas.py              # Pydantic "Contracts" (WorkoutPlan, WorkoutExercise)
├── services.py             # THE FACADE: Entry point for your Django Views
├── telemetry.py            # Logic to extract "Reasoning/Thought" logs & token usage
│
├── agents/                 # THE BRAINS
│   ├── __init__.py         # Exports initialized agents
│   └── workout_architect.py # Specific ReAct logic for the workout agent
│
├── tools/                  # THE HANDS (Interfaces to data)
│   ├── __init__.py         # The "Toolbox" registry
│   ├── db_tools.py         # Django ORM wrappers (Client profile, Exercise library)
│   ├── api_tools.py        # Future: Wearable APIs, Nutrition REST APIs
│   └── mcp_tools.py        # Future: MCP Server integrations
│
└── prompts/                # THE INSTRUCTIONS
    ├── base.py             # Shared persona (Professional Trainer tone)
    └── architect_v1.py     # Task-specific logic (e.g., handling the 'N' integer)
