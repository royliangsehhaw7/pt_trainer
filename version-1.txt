    Setting up static folder / resources
    ===============================================================================
    trainer/
    --- new folder static/
        --- this is the folder for application static file (css,js,png,pdf)
        --- /config/settings.py
                import os       (put at the top)
                STATIC_URL = '/static/'
                STATIC_ROOT = os.path.join(BASE_DIR, 'static')
        --- css/
            will set styles according to modules/process, then will apply in each module Pages
            via {% block custom_styles %}{% endblock %}

            --- trainer.css
            --- exercises.css
            --- tags.css
            --- programs.css
            --- workouts.css

    Setting up application level messages (for displaying CRUD status)
    =================================================================================
    --- /config/settings.py
        from django.contrib.messages import constants as messages
        MESSAGE_TAGS = {
            messages.DEBUG: 'alert-secondary',
            messages.INFO: 'alert-info',
            messages.SUCCESS: 'alert-success',
            messages.WARNING: 'alert-warning',
            messages.ERROR: 'alert-danger',
        }
