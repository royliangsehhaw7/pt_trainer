A. Setup bare django project and blank applications
==========================================================
1. mkdir pt_trainer
2. Setup python environment
    --- CMD: python -m venv venv
    --- CMD: venv/scripts/initialize            (activate environment)
3. Install libraries
    --- CMD: pip install django mysqlclient
4. CMD: django-admin startproject config .      (set django configuration folder as config)
5. CMD: django startapp orm                     (models)
6. CMD: django startapp trainer                 (personal trainer app)
7. CMD: django startapp admin                   (***managing trainer subscription)
8. Register new app in settings.py
    --- INSTALLED_APPS [ ....., 'orm', 'trainer', 'admin']
9.


B. Setup git repository
============================================================
1. Login to GitHub
    --- create a new repository (pt_trainer)
2. Create new python project
    --- mkdir pt_trainer
3. Create .gitignore
4. CMD: git init
5. CMD: git remote add origin https://github.com/royliangsehhaw7/pt_trainer.git
    --- the project url is from github.com repository SSH link in the main repository page
6. CMD: git remote -v
    --- this is to check if git connection is made
7. CMD: git branch --show-current
    --- showing current branch you are working on (since its new, should be master)
8. CMD: git branch -m main
    --- creates a new branch "main"     (???NOT SURE WHY CREATE A NEW BRANCH MAIN INSTEAD OF USING MASTER BRANCH???)

Check in new or amended files
-----------------------------
9. CMD: git status
    --- show all files changes,additions,deletions
    --- RED are pending 'add'
    --- GREE are pending 'commit'
9. CMD: git add .               (add all)
10 CMD: git commit -m "<<remarks">>
11.CMD: git push -u origin main
        --- firstly, check what is the current branch using "git branch --show-current" (should be main)


Revert file changes
--------------------------------
12. git checkout -- <filename>
13. NOTE: if vscode still show pending even after reverting this file
    --- CMD: git restore <filename>
